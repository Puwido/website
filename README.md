# Puwido Portfolio

Open `index.html` in a browser to view the site.

## How to customize
- **Name / text / contact links** → `index.html` (search for "Puwido", "puwido", and the Roblox profile URL).
- **Projects & skills** → `projects.js`.
- **Code snippets, typing lines, hero videos** → top of `script.js`.
- **Colors** → `:root` at the top of `style.css`.

## Assets
- `assets/images/profile.png` – your profile picture (shows a "P" badge if missing).
- `assets/games/*.png` – game thumbnails (set `image` in `projects.js`).
- Optional showcase videos: add an `.mp4` and set `video` in `projects.js`.
- `assets/hero/*.mp4` – background videos for the top section; list them in `heroVideos` in `script.js`.

## Publish free on GitHub Pages
1. Create a GitHub repo and upload all these files.
2. Repo → Settings → Pages → Deploy from branch → `main` / root.
